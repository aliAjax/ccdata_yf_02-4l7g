# Canvas Room

纯前端协作白板工作台，**双击打开 `index.html` 即可使用**，无需构建、无需服务器。

## 结构（样式、规则、页面逻辑分离）

| 文件 | 职责 |
| --- | --- |
| `index.html` | 页面结构，仅以普通 `<script>` 引入 rules.js / app.js |
| `styles.css` | 全部样式 |
| `rules.js` | 纯数据规则层，不碰 DOM：房间隔离、元素/连线模型、每房间撤销重做栈、离线持久化、导出打包与导入校验 |
| `app.js` | 页面逻辑层：渲染、拖拽、内联编辑、连线交互、导入导出，数据操作全部委托给规则层 |

## 功能

- **按房间隔离**：顶栏输入房间号（1–32 位字母/数字/`_`/`-`）回车或点「进入」即可切换/新建。切换房间只显示本房间元素，`?room=房间号` 可直达，「复制链接」带上当前房间。
- **可离线恢复**：所有数据（含各房间撤销/重做栈、最近房间）存于浏览器 localStorage，刷新后停在最近房间与最近状态；存储损坏会自动清洗并提示，不会白屏。
- **撤销 / 重做**：新增、拖动、编辑、清除、连线/删线都进入**当前房间独立**的撤销与重做栈（`Ctrl/⌘+Z`、`Ctrl/⌘+Shift+Z` 或 `Ctrl+Y`）。拖动期间只做预览，松手才产生一条历史；`Esc` 取消拖动不留记录。
- **连线绑定元素**：选择「连线」工具后依次点击两个元素即可连线。连线用 SVG 绘制并吸附元素边缘，拖动端点时实时跟随；删除元素会一并清理关联连线，规则层保证不存在悬空关系。
- **编辑**：双击便签/文本在画布内直接编辑，`Enter` 提交、`Esc` 放弃；`Delete` 删除选中元素或选中连线。
- **导出 / 导入**：导出当前房间为 JSON（元素与连线，带文件标识、版本、房间号）；导入时严格校验，任何损坏（非 JSON、标识/版本不符、非法元素、悬空连线、自连、重复等）都会被拒绝并提示，**当前画面绝不被覆盖**。导入成功后自动切到备份所属房间，且导入本身可撤销。

## 测试

```bash
node test-rules.js   # 规则层：房间隔离、撤销重做、悬空清理、持久化恢复、导入校验（79 项）
node test-dom.js     # 页面层 jsdom 冒烟：渲染、拖拽跟随、编辑、连线、房间切换、导入导出（43 项）
```
