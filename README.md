# Canvas Room

按房间隔离、可离线恢复的纯前端协作白板。直接双击打开 `index.html` 即可使用（普通脚本，无需构建或服务器）。

## 文件结构（样式 / 规则 / 页面逻辑分离）

| 文件 | 职责 |
| --- | --- |
| `index.html` | 页面结构，只负责引入下面三个资源 |
| `styles.css` | 全部样式，不含任何逻辑 |
| `rules.js` | 规则层（与 DOM 无关）：房间数据隔离、每房间撤销/重做栈、连线完整性、localStorage 持久化、导出与导入校验 |
| `app.js` | 页面逻辑：渲染、拖动手势、编辑、工具栏、房间切换与导出导入界面 |
| `test-rules.js` | 规则层行为测试：`node test-rules.js` |

## 功能

- **房间隔离**：房间号决定数据范围。在顶栏输入房间号切换，每个房间的元素、连线、撤销/重做栈完全独立；链接可带 `?room=房间号` 直接进入。
- **离线恢复**：所有改动自动存入 `localStorage`，刷新或重开页面后停在最近房间与最近状态，撤销/重做栈同样保留（每栈上限 50 步）。
- **完整撤销/重做**：新增、拖动（整次拖动为一步）、编辑内容、删除、清空房间、建立与修改连线均进入**当前房间**的栈；快捷键 `Ctrl/⌘ Z` 撤销、`Ctrl/⌘ Shift Z` / `Ctrl Y` 重做。
- **连线绑定**：连线始终绑定两个元素，元素移动时端点实时跟随；选中连线后拖动端点圆点可改线；端点元素被删除时，相关连线在同一事务内一并清理，不会留下悬空关系。
- **导出 / 导入**：按房间导出 JSON；导入时严格校验（应用标识、版本、房间号、元素与端点引用完整性等）。任何一项不合格都不会改动当前画面；导入成功才切换到文件中的房间，且导入本身可撤销。
- **其他**：便签/文本/矩形/圆形、便签颜色、颜色筛选（仅影响显示）、删除选中、清空房间、复制房间链接。

## 测试

```
node test-rules.js
```

覆盖房间隔离、栈独立、刷新恢复、连线级联清理、改线约束、清空撤销、损坏导入不覆盖画面、离线数据自清洗与栈上限等场景。
